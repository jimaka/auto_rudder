## ESC 方案原理与海况适应性

> 素材来源：`control/include/auto_tuner.hpp`（极点配置 + ESC + 稳定门全部实现）、`control/include/autopilot_core.hpp`（每拍数据流）、`docs/工程总体分析与ESC方案原理.md` §3、`docs/auto_tuning/自动调参流程图文详解.md` §4、`docs/adaptive_autopilot_research/自动舵自适应算法调研与最大海况适应性分析.md`（第 8 章最大海况分析、第 14 章结论）。调参链路的层 1（增益调度）与层 2（RLS 辨识 + 极点配置建基线）在前面章节展开，本节聚焦层 3 ESC 的原理推导、海况能力边界与选型依据。

### 为什么需要 ESC：解析解不是最优点

船舶操纵性随船速、载荷、吃水、海况显著变化，任何固定增益都无法全工况最优。工程上采用由粗到细的三层调参结构（设计文档 §3.10）：

| 层 | 机制 | 源码 | 职责 |
|---|---|---|---|
| 层 1 | 增益调度表 | `gain_schedule.hpp` | 按船速段×海况查名义 `Kp/Kd`，管"快变量"（航速），是兜底 |
| 层 2 | RLS 辨识 + 极点配置 | `nomoto_identifier.hpp` + `auto_tuner.hpp` | 在线辨识 Nomoto `K̂/T̂`，解析反解 PD 增益，建立基线 |
| 层 3 | ESC 极值搜索 | `auto_tuner.hpp` | 在基线附近注入微小正弦扰动，实测性能梯度，连续微调 |

层 2 的极点配置由闭环特征方程 `T·s² + (1+K·Kd)·s + K·Kp = 0` 对照标准二阶系数反解（全仓库唯一定义在 `AutoTuner::polePlacement()`，`auto_tuner.hpp:228-237`）：

```
Kp = ωn²·T̂ / K̂
Kd = (2ζ·ωn·T̂ − 1) / K̂        （ζ=0.85，ωn=0.20 rad/s；Kd<0 时钳 0）
```

但真实船舶与 Nomoto 一阶模型 `T·ṙ + r = K·δ` 总有偏差——解析解只是"理论最优点附近"，不是最优点本身。层 3 的 ESC（Extremum Seeking Control，极值搜索控制）不依赖模型精度，直接在被控对象上**实测**性能对增益的梯度，把模型误差"吃掉"。

### ESC 原理推导：扰动–解调式极值搜索

#### 物理直觉

ESC 是无模型在线优化：不看成本曲面，用"探针"轻轻晃动增益（±5% 正弦载波），观测性能指标 J 的"回声"——若 J 跟着载波同相起伏，说明当前增益偏高（增益增大则 J 增大）；反相则偏低；相关输出趋零则已在谷底。"乘以同相载波再平均"本质是一台锁相放大器，把含梯度信息的基波分量从直流和谐波中检出来，然后沿负梯度方向走一步。

#### 数学流程（四步）

被整定对象是 PD 增益 `Kp`、`Kd` 本身。设单参数 `θ`，性能 `J(θ)` 在最优点 `θ*` 附近光滑，取二阶泰勒展开并叠加摄动 `θ(t) = θ̄ + a·sin ωt`：

```
J(θ) ≈ J* + ½·J''·(θ−θ*)²
代入摄动后分解为三项：
J(t) ≈ [J* + ½J''(θ̄−θ*)²]          ← 直流/慢变项
     + [J''(θ̄−θ*)·a·sin ωt]          ← 基波（含梯度信息）
     + [¼J''a²(1 − cos 2ωt)]         ← 二倍频谐波
```

信号链逐级作用（图文详解 §4.2）：

1. **高通去直流**：HPF 滤掉第一项，输出 `≈ J''(θ̄−θ*)·a·sin ωt`（谐波远小于基波，忽略）；
2. **乘以同相载波（解调）**：`y·sin ωt = a·J''(θ̄−θ*)·sin²ωt = (a/2)·J''(θ̄−θ*)·(1 − cos 2ωt)`；
3. **窗口平均**：`cos 2ωt` 被平均掉、`sin²` 均值为 1/2，得 `mean ≈ (a/2)·J''(θ̄−θ*) = (a/2)·∂J/∂θ|_θ̄`——**解调平均值正比于当前点梯度**。代码里归一化系数 `ĝ = 2·Σ(y·载波)/(a·N)`（`escStep()`，`auto_tuner.hpp:399-405`）中的 2 和 a 恰好把这个 `a/2` 归一掉；
4. **积分器更新**：`θ̄ ← θ̄ − η·ĝ`。`θ̄` 在最优点右侧时 `ĝ>0` 左移，左侧时右移——自动爬向 J 谷底。

#### 双参数同时调：正交载波

`Kp` 用 `sin` 载波、`Kd` 用 `cos` 载波，由正交性 `mean(sin·cos)=0`，两路解调互不串扰——一次扰动同时估出 `∂J/∂Kp` 与 `∂J/∂Kd`。

#### 收敛前提：时间尺度三分离

```
闭环动态（秒级）  ≪  载波周期（百秒级）  ≪  积分器适应（多窗口）
```

载波必须慢到闭环能"跟上"扰动（否则 J 来不及响应、梯度信号衰减），又要快到在船况漂移之前完成估计。理论背书是 Krstić–Wang 平均化 + 奇异摄动稳定性证明（局部指数稳定）。本工程默认 `ω = 0.05 rad/s`（`escFreq`，周期约 126 s）、窗口 60 s——该默认值与窗口长度存在张力，见末节"待确认项"。

### 代价函数：ITAE + 操舵惩罚

`computeJ()`（`auto_tuner.hpp:214-223`）定义窗口性能指标，每拍增量在 `accumulate()`（:366-367）累积：

```
J = ∫₀^Tw ( t·|e(t)| + wU·|δ(t)| + wDu·|δ̇(t)| ) dt
Tw = 60 s（windowSec），wU = 0.01（舵角/能耗），wDu = 0.005（舵角变化率，抑抖振护舵机）
```

- `t·|e|`：ITAE 时间加权，误差权重随时间线性增长，重罚收敛慢、鼓励快速镇定；
- 样本存 `RingBuffer<double, 3000>`（60 s × 50 Hz，主循环零堆分配）；窗口**非重叠**，结算后清零。

### 工程实现：信号链与代码逐环节对应

| 环节 | 公式 | 代码位置 | 参数 |

工程要点：

- **扰动只存在于输出给 PD 的增益中，不持久化**——`curKp_/curKd_` 保存去载波的中心增益；
- **P11 整改教训**（`auto_tuner.hpp:8-12` 头注释）：旧实现①扰动未真实注入（窗内增益恒定）→ J(t) 没有基波分量，解调恒为零；②HPF/LPF 系数按 `dt=0.02 s` 设计却用在每 60 s 才来一个的样本上 → 梯度衰减 2~3 个数量级，"调参结果与初值逐位相同"。结论：**ESC 各环节运行在不同时间尺度（扰动/解调在每拍、LPF 在窗末），滤波器系数必须用各自环节的真实采样周期计算**。

### 安全机制：ESC 更新不直接生效

自动改增益是危险操作，一切增益变更必须过四道防线（`docs/工程总体分析与ESC方案原理.md` §3.5）：

1. **四条件稳定门**（`stabilityCheck()` :241-254）：用辨识快照 `K̂/T̂` 反解闭环特征——`ωn=√(Kp·K̂/T̂) ≤ 0.5 rad/s`、`ζ=(1+Kd·K̂)/(2√(T̂·Kp·K̂)) ≥ 0.6`、K/T 非退化且 `Kp>0`、实测振荡峰-峰值 ≤ 5°（`oscMax`），全过才放行；
2. **回退**（`settleWindow_()` :333-345 → `revert()` :429-432）：窗口结算不过门则增益恢复到基线——基线永远是"已验证安全"的锚点；辨识快照无效时保守拒绝；
3. **振荡检测**（`OscillationDetector` :257-292）：航向误差过零结算峰-峰幅值（保守取大 + 0.9/0.1 平滑衰减），且**航向参考稳定满 30 s（`kOscRefSettleSec`）后才喂入**——机动期间的误差摆动是指令响应而非闭环振荡；
4. **速度门控**：船速 > 15 kn（`highSpeedDeactivateKn`）调参整体去激活，仅层 1/辨识运行。

生命周期配套：**漂移重基线**（`applyEstimate_()` :308-329）——`K/T` 估计相对基线漂移 ≤ 25%（`kReBaselineTol`）时不动作、交给 ESC 自治微调；超阈值说明船况真变 → 重新极点配置 + 过稳定门 + `rebaseEsc()`（:438-450）清零 ESC 积分器/解调/窗口样本（旧梯度围绕旧增益旧模型测得，不得施加到新基线），**载波相位刻意保留**以防重锚拍突跳。**挂起**（`suspend()` :199-203）：切到 MANUAL/HOLD 时清测量状态、保留基线，回来无缝续上。

### 为什么从基线出发微调，而不是全量在线寻优

这是方案选型的核心决策，理由有五：

1. **ESC 的数学定位就是局部方法**。梯度估计来自最优点邻域的二阶泰勒展开，只在 `θ̄` 接近 `θ*` 时成立；它的定位是"单点、局部梯度、低维的确定性策略搜索"，天花板是只能在 PD 结构内寻优（调研结论 §3.8.4）。把搜索空间压到基线的小邻域，恰好匹配这个能力边界。
2. **基线是"已验证安全"的锚点**。基线由极点配置从辨识 `K̂/T̂` 解析建立、经稳定门背书；ESC 每步更新不过门即回退基线。若做全量寻优，参数空间中大部分区域没有安全性背书，回退机制也无从依附。
3. **时间尺度代价不可承受**。ESC 收敛前提是载波远慢于闭环动态，收敛以分钟计（仿真典型船 1200 s 跑 18 个窗口收敛，慢于 L1/滑模类方案）。全量搜索意味着在大参数空间里逐步爬行，收敛时间对实船不可接受；基线用解析解一次性把增益拉到最优附近，ESC 只负责吃掉残余模型误差——"比单层方法既快又稳"（图文详解 §6.1）。
4. **与工业界 50 年分工共识同构**。自 KADPIL（1974）以来，"增益调度管快变量（船速）、自适应管慢变量（海况/载况残余失配）"就是商用自动舵的行业结构（Kongsberg/Anschütz/Raymarine 在役产品沿用）；本项目"调度表 → 辨识+极点配置基线 → ESC 微调"与其一一对应。
5. **激励主动性绕开被动学习的死穴**。保向工况激励贫乏是一切被动自适应（纯 RLS 自校正/NN）的死穴——"需要学习的时候学不动"。ESC 主动注入扰动，结构性绕开持续激励（PE）问题；而全量在线学习类方案（NN/RL）在实船上既缺激励又不可探索。

### 最大海况适应性：方案能力边界

#### 海况刻度与本项目工作域

- 国际通用 WMO/Douglas 分级以有义波高 `H₁/₃` 划分 0–9 级；本项目增益调度采用内部海况刻度 **0..3 级**，大致对应 WMO 0–3（`H₁/₃ ≤ 1.25 m`，"轻浪及以下"）标称工作域；
- 对 25 kn 级游艇，**海况 4–5（`H₁/₃` 1.25–4 m）是常规运营可能遭遇的上限**，作为"最大海况"分析目标；**海况 ≥6 时自动舵任务从"精确航向保持"退化为"安全降级"**——保船不保精度；
- 工程设计应直接用波谱参数而非海况码：对自动舵真正起作用的是**遭遇谱**，`ωe = |ω − (ω²U/g)·cosχ|`。随浪（χ=0°）时映射非单调、在 `ω=g/(2U)` 处折叠——25 kn 下折叠点 ≈ 0.38 rad/s，海况 4 的谱峰（0.8–1.0 rad/s）能量被压回 `ωe<0.3 rad/s` 的操纵频段，这是随浪航向保持困难、波浪滤波难以奏效的频域解释。

#### 高海况对自动舵的扰动机理（调研第 8 章）

| 机理 | 内容 | 对本方案的冲击 |
|---|---|---|
| 一阶波浪力 | 波幅同阶的线性振荡力（游艇典型 0.3–1.5 rad/s），均值零，叠加在低频操纵运动上 | 不应进入反馈——舵无法抵消波频振荡，硬跟只会舵机空转磨损；进入辨识/ESC 则成"假激励" |
| 二阶慢漂力 | 与波幅**平方**成正比的慢变漂力/漂转力矩（`F ∝ H₁/₃²`），叠加大风/流低频力矩 | 航向稳态偏差主源，需积分作用或低频补偿抵消（本方案 PD 故意无积分，靠航迹闭环补偿） |
| 舵机硬约束 | 舵角限幅 ±35°（舵 35–45° 失速）、舵速限制（SOLAS 最差工况下限约 2.3°/s） | 大信号下实际舵角滞后舵令，等效相位滞后侵蚀稳定裕度；大舵角失速区等效 K 随舵角**下降**，与 Nomoto 线性假设冲突 |
| 低速大漂角 | 高海况常伴降速：`K ∝ U` 舵效减弱，风与二阶漂力相对权重上升，船带大漂角航行 | 低速+大浪+大漂角是最恶劣组合工况，可用舵效裕度被进一步压缩 |

#### 各海况下本方案的能力边界

| 海况 | 本方案状态 | 能力边界 |
|---|---|---|
| 0–2（标称） | 调度表 + 辨识 + 基线 + ESC 全链路工作 | 设计指标达成域（静水 ±1°、2 级海况 ±2°/1σ）；仿真 1200 s 全链路收敛试验验证（`--tune`，J 93639.7→93221.2，末 3 窗散布 ≤10%，converged=1） |
| 3（内部刻度上限） | 全链路可工作，ESC 梯度信噪比下降 | 调度域边界；调研建议补波浪滤波后才稳妥 |
| 4–5（最大海况） | **当前缺波浪滤波是最大短板**：波频分量淹没 ESC 激励抖动、梯度失真；调度表外插无保证 | 需配齐保护后才可行：冻结 ESC、切保守 PD 基线、限舵/降速提示（降级链，P1 建议，当前未实现） |
| ≥6 | 一切算法统一安全降级 | 超出设计目标，保船不保精度 |

#### 已落地的保护与已识别的短板

已落地：辨识器输入用的是**实际舵角反馈**（`autopilot_core.hpp:163` `identifier_.update(s.rudderDeg, s.rateDegS, dt)`，`SensorInput.rudderDeg` 为舵角反馈而非舵令 δ_cmd）——这正是调研强调的对舵饱和鲁棒的关键经验（Lauvdal & Fossen 1998），当前实现已满足；速度门控、振荡门控、稳定门/回退构成现有安全网。

已识别短板（调研结论按优先级）：

- **P0 补波浪滤波**（陷波或 Kalman）：`control/include/` 当前无任何陷波/Kalman/波浪滤波环节（已核实），一阶波频分量先于反馈与辨识被滤除是所有自适应机制在海况 3 以上正常工作的前提；
- **P0 ESC 高海况保护三件套**：dead-zone（误差能量低于阈值冻结更新）、泄漏项（防漂移）、激励频率避开遭遇谱峰（0.05–0.2 Hz，即 0.3–1.26 rad/s）；
- **P1 海况超阈值降级链**：内部 0..3 级之上显式扩展调度域到海况 4–5，超上限时冻结 ESC、切预存保守 PD 参数、限舵/降速提示，并纳入 HIL 验证。

### 选型结论：为什么是 ESC，而不是其他自适应/学习类方案

调研（`docs/adaptive_autopilot_research/`，14 章谱系：MRAC / STR·LQG / 自适应 PID·增益调度 / 模糊 / NN / L1·滑模 / RL / MPC 等）的结论：**"ESC 与 50 年工程共识同构、方向正确"**。

| 强化学习 | ◐ | ◐ | ○（固定策略+监督层） | ✗ | 离线域随机化训练，禁在线探索 |

#### 选中 ESC 的四条决定性理由

1. **与工业界带宽分离分工同构**：调度表管快变量（航速）、自适应管慢变量（海况/载况残余失配），与 KADPIL（1974）以来的商用实践一致——自适应自动舵不是前沿探索，而是 50 年实船验证的成熟方向（Åström/Källström 自校正油轮自动舵 130 余次实船试验，节油 0.3–0.9%；恶劣海况恰是收益最大工况，KADPIL 2 在 8 级风下节油增益 1.4%，高于和风的 0.5%）。
2. **可解释、可认证**：ESC 只动 `K/T`、`Kp/Kd` 少量物理参数，有平均化稳定性理论背书，参数可限幅、可监控——相对 NN/RL 的取证困难，这是决定性工程优势；IMO MSC.64(67) 自 1996 年起即在性能标准中容纳"自动适应"方案。
3. **激励主动性**：见上节第 5 条——ESC 主动注入扰动，结构性绕开被动自适应的 PE 死穴。
4. **数学定位清晰、样本代价极低**：ESC 与 RL 同属无模型在线优化，但它是"单点、局部梯度、低维的确定性策略搜索"，不需要 RL 的海量试错；天花板明确（只能在 PD 结构内寻优），风险边界也明确。

对照落选方案：MRAC/STR 需陷波+鲁棒化修正才可达海况 4–5，且高海况下甚至要关闭辨识；NN/RL 分布外无保证、实船在线探索不可接受，只宜离线或监督模式；滑模抖振与舵机磨损直接冲突；L1 自适应是文献中商用化最成功的高海况方案（Raymarine Evolution），与本项目"ESC 慢调参 + PD 基线"的时间尺度分离思想同构——**若未来升级自适应方案，L1 是迁移成本最低的路径**（调研第 8 章建议 5）。

#### 当前实现的已知限制（诚实清单）

- 无显式收敛停机判据——靠稳定门+回退兜底，外部以 J 平台判收敛；
- 固定步长 `escStep=0.02`（无自适应步长）；LPF 平滑很弱（`αL≈0.857` 权重给新样本）；
- 梯度估计量纲为"J 对增益相对摄动"，更新律却做绝对加法——工程近似，由相对限幅兜底；
- 扰动注入影响操舵平顺性；收敛分钟级；辨识误差直接传导到极点配置（仿真典型船辨识误差 +18.2%/+18.5% 仍收敛）；
- 慢船（T=20）工况下 ESC 被稳定门按预期阻断、钉在安全增益——保守行为符合设计，但记录为已知限制；
- 文档已声明未实现项：`ζ/ωn` 船速分段（当前单组 0.85/0.20）、回退缓存深度 3（当前单组基线）、代价函数升级为操舵附加阻力型 `J=E[ψ_e²+λδ²]`（λ≈1/12，节能口径，P1 建议，与 `docs/ship_energy_research/` 互为表里）。

### 代码↔文档不一致与待确认项
