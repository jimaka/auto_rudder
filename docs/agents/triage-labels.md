# Triage Labels（分诊标签）

这些 skill 以五个标准分诊角色来表述。本文件将这些角色映射到本仓库工单系统中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 我们工单系统中的标签 | 含义                                       |
| -------------------------- | -------------------- | ------------------------------------------ |
| `needs-triage`             | `needs-triage`       | 维护者需要评估这个 issue                   |
| `needs-info`               | `needs-info`         | 等待报告者提供更多信息                     |
| `ready-for-agent`          | `ready-for-agent`    | 已完整定义，可以交给 AFK agent             |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现                               |
| `wontfix`                  | `wontfix`            | 不会处理                                   |

当某个 skill 提到某个角色时（例如"应用 AFK-ready 分诊标签"），使用本表中对应的标签字符串。

编辑右列以匹配你实际使用的任何词表。
