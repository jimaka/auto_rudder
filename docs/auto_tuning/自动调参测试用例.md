# 船舶自动调参测试用例

> 对象工程：`control/`（自动舵控制算法，C++ 头文件库）
> 被测范围：自动调参链路 —— RLS 在线辨识（Nomoto K/T）→ 极点配置（基线）→ ESC 极值搜索（在线微调）→ 稳定性监控/回退
> 关联文档：`docs/auto_tuning/自动调参流程图文详解.md`、`CONTEXT.md`（领域术语）、`control/控制算法开发文档.md` §5~§6
> 版本日期：2026-08-06

## 1. 目的与范围

验证船舶自动调参在仿真闭环下满足以下要求：

1. **辨识收敛**：Nomoto 模型参数 K̂/T̂ 在 Z 形激励下收敛到真值附近（偏差 ≤ 25%），且物理合理性检查 `valid()` 通过；
2. **基线建立**：辨识有效后经极点配置建立基线，增益所有权从调度表移交调参器；
3. **ESC 收敛**：窗口性能指标 J 进入平台（末 3 窗相对散布 ≤ 10%），增益在基线附近有界微调，不劣化（末窗 J ≤ 首窗 × 1.02）；
4. **安全兜底**：稳定门/回退/振荡检测/速度门控在异常条件下拒绝或撤销危险增益更新；
5. **端到端可复现**：`ar_sim --tune` 一次运行即可导出 K̂/T̂、J、增益全轨迹并判定收敛。

不在本次范围内：HIL 半实物、实船海试、BSP/IO 层、GNSS 定位解算。

## 2. 被测链路与接口

```
调度表查询 ──▶ 喂辨识器（自降频 1 s/拍）──▶ AutoTuner::tick() ──▶ PD 闭环
                （NomotoIdentifier）          （速度门控/辨识评估/样本累积/
                                                ESC 窗口结算/扰动注入）
                Z 形辨识试验收官 ──▶ AutoTuner::establishBaseline()
```

被测源码：

| 模块 | 文件 | 被测动作 |
|---|---|---|
| 在线辨识 | `control/include/nomoto_identifier.hpp` | `update(δ, r, dtNow)`、`K()/T()/valid()/excited()`，自降频 |
| 自动调参 | `control/include/auto_tuner.hpp` | `tick()`、`establishBaseline()`、`suspend()`、`polePlacement()`、`stabilityCheck()`、`computeJ()`、`currentGains()` |
| 集成 | `control/include/autopilot_core.hpp` | `startIdentifyTrial()`、`headingControlStep()` 每拍转发 |
| 仿真 | `control/sim/simulator.hpp` | `runIdent()`、`runEsc()`、`runIdentTrial()`、`runTuneConvergence()` |
| 可视化 | `control/tools/plot_convergence.py` | 收敛效果图生成 |

## 3. 测试环境与前置条件

| 项 | 说明 |
|---|---|
| 编译器 | GCC 15.2（C++17，`-Wall -Wextra -Wpedantic`） |
| 单元测试 | GoogleTest 1.14+（本机可用 conda 自带 gtest） |
| 仿真 | `ar_sim`（50 Hz 闭环，NomotoPlant + 舵机一阶/限幅） |
| 绘图 | Python 3 + matplotlib/numpy（CJK 字体 Noto Sans CJK） |
| 数据 | `docs/auto_tuning/data/tune_convergence_*.csv` |

构建与运行：

```bash
cmake -S control -B build -DAR_BUILD_TESTS=ON -DAR_BUILD_SIM=ON
cmake --build build -j
ctest --test-dir build --output-on-failure
./build/sim/ar_sim --tune --K 0.2 --T 8 --seconds 1200 --out tune.csv
python3 control/tools/plot_convergence.py tune.csv --trueK 0.2 --trueT 8 -o docs/auto_tuning/figures
```

## 4. 用例设计总则（判定口径）

| 判据 | 阈值/口径 | 依据 |
|---|---|---|
| 辨识收敛 | \|K̂−K\|/K ≤ 25% 且 \|T̂−T\|/T ≤ 25%，`valid()`=true | `--trial`/`--esc` 既有容差 |
| 基线建立 | `tuner.baselineEstablished()`=true，增益从调度值跳变到极点配置值 | R1 接口 |
| ESC J 平台 | 基线后 ≥ 4 个窗口，末 3 窗 J 相对散布 (max−min)/min ≤ 10% | 收敛试验新增判据 |
| J 不劣化 | 末窗 J ≤ 首窗 J × 1.02 | 收敛试验新增判据 |
| 数值稳定 | 全程 ψ/r/增益有限，Kp ∈ (0, 5×Kp0]，Kd ∈ [0, 5×Kd0) | `runEsc` 既有精神 |
| 稳定门 | ζ̂ ≥ 0.6、ω̂n ≤ 0.5 rad/s、振荡幅值 ≤ 5° | `stabilityCheck()` |

## 5. 用例清单

### 5.1 在线辨识（NomotoIdentifier）

| ID | 用例 | 级别 | 步骤 | 预期/通过判据 | 自动化 |
|---|---|---|---|---|---|
| U01 | 无噪 Z 形数据收敛 | 高 | 非对称 Z 形（±25°、8/3 拍）回灌 400 拍（1 s/拍） | K̂ 误差 < 0.05、T̂ 误差 < 2 s；excited/valid 为 true | `ConvergesOnNomotoData` |
| U02 | 50 Hz 调用自降频收敛 | 高 | 同一激励按 50 Hz 回灌 400 s，内部 1 s 一拍 | 收敛误差与 1 s 直调等价 | `SelfDecimatesAtAnyCallRate` |
| U03 | 无激励保护 | 高 | 全程 δ=1°、r=0.1°/s（低于激励门限） | 恒返回 false，θ 保持初值，excited=false | `NotExcitedWhenIdle` |
| U04 | 超限/NaN 防御 | 高 | 注入 δ>35°、r>30°/s、NaN 样本 | 该拍被丢弃，不污染 θ/P，后续收敛与参考运行相当 | `RejectsOutOfRangeInput`、`RecoversAfterNaNInput` |
| U05 | 物理合理性 | 中 | 正常收敛后检查 | K̂∈(0,2]、T̂∈[1,60] 时 valid=true；越界为 false | `InvalidWhenOutOfRange` |
| U06 | 慢船激励适配（边界） | 中 | K=0.1/T=20，leg=15 s vs 60 s 对比 | leg=15 s 时 K̂/T̂ 偏差约 +81%/+89%（FAIL 记录）；leg=60 s 时 +3%/+3%（通过） | `ar_sim --tune --K 0.1 --T 20 --leg 60` |

### 5.2 极点配置与稳定门（AutoTuner）

| ID | 用例 | 级别 | 步骤 | 预期/通过判据 | 自动化 |
|---|---|---|---|---|---|
| U07 | 极点配置还原目标 | 高 | K=0.2/T=8、ζ=0.85、ωn=0.25 | 反算 ωn=0.25（1e-6）、ζ=0.85（1e-3） | `PolePlacementProducesTargetZetaWn` 等 |
| U08 | 退化参数拒绝 | 高 | K=0 或 T=0 | 返回 false，不产生增益 | `PolePlacementRejectsDegenerate` |
| U09 | 负 Kd 钳位 | 高 | 小 ωn 使公式给出负 Kd | Kd 钳到 ≥ 0 | `PolePlacementClampsNegativeKd` |
| U10 | 稳定门放行/拦截 | 高 | 健康增益 vs 低 ζ、高 ωn、振荡 8° | 健康通过；三异常全拒 | `StabilityCheck*` 系列 |
| U11 | 振荡检测 | 中 | ±3° 正弦误差 200 拍 | 峰-峰幅值 ≈ 6°（±1°）；reset 后历史峰不泄漏 | `OscillationDetector*` |

### 5.3 ESC 极值搜索（AutoTuner tick 驱动）

| ID | 用例 | 级别 | 步骤 | 预期/通过判据 | 自动化 |
|---|---|---|---|---|---|
| U12 | 无基线直通调度增益 | 高 | 未建基线时 tick 100 拍 | 输出增益 = 调度值，无载波，基线不建立 | `NoBaselinePassesScheduleGainsThrough` |
| U13 | 载波真实注入 | 高 | 建基线后跑 2 个载波周期 | 输出增益覆盖 ±escAmp 相对调制（峰-峰 ≈ 2·a·Kp） | `EscDitherModulatesGains`、`EscDitherReachesPdGainsAfterBaseline` |
| U14 | 窗口更新有界 | 高 | 10 个窗口误差渐增 | 每窗更新 ≤ max(10%·old, 1e-3)，或被稳定门拒绝回退 | `WindowSettleUpdateIsClamped` |
| U15 | ESC 朝最优方向调参 | 高 | 整闭环（tick+PD+Nomoto），起点 Kp 偏低 | 若干窗口后 Kp 增大且 J 下降 | `EscTunesKpTowardOptimum` |
| U16 | 零 Kd 解锁 | 中 | 基线 Kd=0，注入与 cos 载波负相关成本 | Kd 从 0 上移且逐窗 ≤ 绝对下限×3 | `EscUpdateUnsticksFromZeroKd` |
| U17 | 结算接受/回退 | 高 | 快照健康 vs 快照无效 | 健康时接受（Kd 上移有界）；无效时 revert 回基线 | `SettleAcceptsUpdateWhenEstimateHealthy`、`SettleRevertsToBaselineWhenEstimateInvalid` |
| U18 | 重锚清积分器 | 高 | 半窗累积后二次建基线 | computeJ=0、零成本整窗结算后增益保持新基线 | `RebaselineClearsIntegratorState` |

### 5.4 安全机制与生命周期

| ID | 用例 | 级别 | 步骤 | 预期/通过判据 | 自动化 |
|---|---|---|---|---|---|
| U19 | 速度门控 | 高 | 20 kn vs 10 kn 各一拍 | >15 kn 时 `tuner.enabled()`=false；≤15 kn 时 true | `HighSpeedDisablesTuner`、`LowSpeedEnablesTuner` |
| U20 | 振荡回退 | 高 | ESC 上调 Kp 后注入峰-峰 12° 振荡 | 窗口结算被拒，增益恢复基线 | `EscFallbackRestoresBaselineOnOscillation` |
| U21 | 参考机动期振荡门控 | 高 | 参考每 15 s 翻转、误差 ±8° 摆动 60 s | 检测器幅值保持 0；参考稳定 30 s 后恢复测量 | `OscDetectorStarvedDuringReferenceMotion` |
| U22 | 挂起清测量态 | 中 | 自动模式跑一段后切 MANUAL/HOLD | `suspend()` 清窗口/解调/HPF/梯度，保留基线 | `autopilot_core` 模式切换用例 |
| U23 | 辨识不覆写 ESC 增益 | 高 | K/T 漂移 < 25% 时喂辨识 | 增益钉在旧基线；漂移超阈值后显式重基线 | `IdentUpdatesDoNotOverwriteEscGains` |

### 5.5 端到端收敛（ar_sim --tune）

| ID | 用例 | 级别 | 步骤 | 预期/通过判据 | 自动化 |
|---|---|---|---|---|---|
| U24 | 典型船全链路收敛 | 高 | K=0.2/T=8、10 kn、Z 形 ±40°/15 s、1200 s | 基线建立 + 辨识 valid + ≥4 窗 + 末 3 窗 J 散布 ≤10% + J 不劣化 + 数值有界 → converged=1 | `--tune --K 0.2 --T 8 --seconds 1200` |

## 7. 结论与已知限制

1. 自动调参链路在典型船（K=0.2/T=8）与快船（K=0.5/T=3）上完成参数收敛：辨识误差 ≤ 18.5%，ESC 窗口 J 进入 ±2% 平台，全程数值有界；
2. 慢船（K=0.1/T=20）暴露两点限制，均按设计行为记录：
   - 默认 15 s Z 形激励对 T=20 s 船太快，辨识偏差 +81%/+89%（激励需按 T 缩放，≥2T 后降至 +3%）；
   - 适配激励下辨识收敛，但早期基线 Kd 被钳 0 且振荡幅值 > 5°，稳定门阻断重基线/ESC，增益钉在保守值——安全机制按预期拒绝危险调参，慢船参数面（ζ/ωn 分段、载波周期、窗口对齐）留作后续项；
3. 既有 `--validate` 矩阵中 `slow_nodist`（调节时间 35.7 s > 30 s）与 `typical_dist`（操舵频次 12 次/min > 6）为 M1 指标项 FAIL，与自动调参链路无关，未在本用例集内处理。
