# 自动舵工程总体分析与 ESC 方案原理

> 本文档是对 `auto_rudder` 工程（船舶自动舵）的全面分析结论，重点阐述自动调参方案中 ESC（Extremum Seeking Control，极值搜索控制）的原理、实现与验证。分析依据：`control/include/` 源码、根目录三份设计文档（AR-DOC-2026-001/002/003）、`docs/auto_tuning/` 专项文档、`docs/adaptive_autopilot_research/` 调研文档、`control/tests/` 测试与 `control/sim/` 仿真。

## 1. 工程全景

船舶自动舵（Autopilot）：面向 25 kn 级中小型游艇（船长 12~18 m），实现航向保持与机动控制。

- 关键指标：航向保持精度 ≤±1°（静水）/±2°（2 级海况，1σ）；控制周期 20 ms（50 Hz）；30° 阶跃超调 ≤10%、5% 调节时间 ≤30 s；操舵频次 ≤6 次/分。
- 核心架构决策：**控制闭环在航向层完成**，GNSS 定位仅作辅助；控制律采用 **PD（故意无积分项）**——避免低速/长时漂移与积分饱和，PD 固有静差由"位置反馈实现航迹闭环"补偿。
- 软件分层："算法 → 仿真 → 测试 → 工具 → 界面"五层。算法层为 8 个 header-only C++17 模块（namespace `ar`），设计原则：纯算法无 IO（传感器/舵机/EEPROM 经 `std::function` 注入）、确定性（LCG 伪随机）、主循环零堆分配（固定 RingBuffer）。

## 2. 控制核心模块要点

### 2.1 PD 航向控制器（`pd_controller.hpp`）

处理链（顺序为强约束）：**死区（0.3°）→ 微分一阶低通（τ=0.2 s）→ PD 律 `out=Kp·e+Kd·ė` → 舵角限幅 ±35° → 舵速限幅 10°/s（0.2°/拍）→ 输出量化 0.1°**。对误差微分（非测量微分），首拍 derivRaw=0 防微分冲击。`setGains/setDt` 轻量改参不清内部状态（P1），供调度/ESC 每拍调用；`initBaseline(实际舵角)` 防切入瞬跳（P11）；`saturate()` 公开供机动 RUDDER 段复用（P7）。

### 2.2 增益调度（`gain_schedule.hpp`）

船速（4 段）×海况（0..3）共 14 条默认表，速度维**段中点锚定线性插值**（P5，消除段切换跳变）。原则：速度越高、海况越大，增益越小。只按速度+海况查表，不直接用 Nomoto K/T。

### 2.3 Nomoto 在线辨识（`nomoto_identifier.hpp`）

- 模型：一阶 Nomoto `T·ṙ + r = K·δ`；回归化 `y_k = r_k`，`φ_k = [δ_k/50, −dr_k]ᵀ`，`θ=[K,T]ᵀ`（归一化消除量级病态）。
- 算法：带遗忘因子 λ=0.98 的标准 RLS 三式（增益/残差更新/协方差），P 阵对角保底 1e-3 防塌陷。
- 工程化：**自降频**（任意频率调用，内部攒满 1 s 才做一拍，Δt 自测）；**激励门控** `|δ|>3° 且 (|r|>0.5°/s 或 |dr|>0.2°/s²)`——稳态直航 dr≈0 时 T 欠定，T 的信息只藏在转向反向（r 过零）的高 dr 瞬态；入口范围检查 + NaN 防御，被拒拍不写 prevR_ 防毛刺毒化差分锚点（P11）；`valid()` 物理门限 K∈(0,2]、T∈[1,60] s。

### 2.4 参数存储（`param_store.hpp`）

EEPROM 区块 A 舵角标定 / B 模型 K/T / C PD 增益 / D 调度表 + version/timestamp/CRC32；显式小端序列化（跨平台可复现）。已知不一致：`load()` 只验 CRC，`validateRange()` 需调用方显式补做。

### 2.5 机动序列器（`maneuver_sequencer.hpp`）

Leg = {Mode: HEADING/RUDDER, Trigger: HEADING_REACHED/TIME/RATE/NONE, target, threshold, next} 显式链表状态机。预置 6 种机动：Williamson（救生回转）、U-Turn、Zigzag（兼作辨识激励源）、Circles、Cloverleaf（四叶）、Search（扩张方搜）。HEADING_REACHED 触发**方向敏感**（`cum·thr ≥ thr²`，P12：反舵后惯性顺漂不得误切段）。

## 3. ESC 方案原理（核心）

### 3.1 为什么需要 ESC：三层调参架构

船舶操纵性随船速/载荷/吃水/海况显著变化，固定增益无法全工况最优。工程采用由粗到细的三层结构（设计文档 §3.10）：

1. **层 1 增益调度表**：按船速×海况查表给名义增益，管"快变量"（航速），是兜底；
2. **层 2 RLS 辨识 + 极点配置**：在线辨识 K̂/T̂，解析反解 PD 增益建立**基线（baseline）**；
3. **层 3 ESC 极值搜索**：真实船舶与 Nomoto 一阶模型总有偏差，解析解不是最优点——ESC 在基线附近注入微小正弦扰动，**实测性能梯度**做连续在线微调，不依赖模型精度。

层 2 极点配置由闭环特征方程 `Ts²+(1+K·Kd)s+K·Kp=0` 对照标准二阶系数反解（全仓库唯一定义在 `AutoTuner::polePlacement`，`auto_tuner.hpp:228-237`）：

```
Kp = ωn²·T̂/K̂
Kd = (2ζ·ωn·T̂ − 1)/K̂        （ζ=0.85，ωn=0.20 rad/s；Kd<0 钳 0）
```

### 3.2 代价函数

ITAE + 操舵惩罚（`computeJ()` `auto_tuner.hpp:214-223`，每拍增量 `accumulate()` :366-367）：

```
J = ∫₀^Tw ( t·|e(t)| + wU·|δ(t)| + wDu·|δ̇(t)| ) dt
Tw = 60 s（windowSec），wU = 0.01（舵角/能耗），wDu = 0.005（舵角变化率，抑抖振护舵机）
```

- `t·|e|`：ITAE 时间加权，重罚收敛慢；
- 样本存 `RingBuffer<double,3000>`（60 s×50 Hz，零堆分配）；窗口**非重叠**，结算后清零。

### 3.3 数学原理：摄动-解调-积分

被整定对象是 **PD 增益 Kp、Kd 本身**。设 J(θ) 在最优点附近二阶泰勒展开 `J ≈ J* + ½J''(θ−θ*)²`，叠加摄动 `θ(t) = θ̄ + a·sin ωt` 后，J(t) 分解为**直流项 + 基波（含梯度信息）+ 二倍频谐波**：

1. **高通滤波**去直流，输出 ≈ `J''(θ̄−θ*)·a·sin ωt`；
2. **乘以同相载波（解调）**：`y·sin ωt = (a/2)·J''(θ̄−θ*)·(1 − cos 2ωt)`；
3. **窗口平均**：cos 2ωt 被平均掉、sin² 均值为 1/2，得 `mean ≈ (a/2)·∂J/∂θ`——解调平均值**正比于当前点梯度**。这就是归一化系数 `ĝ = 2Σ(y·载波)/(a·N)` 中 2 和 a 恰好归一掉 a/2 的由来；
4. **积分器更新** `θ̄ ← θ̄ − η·ĝ`，自动爬向 J 谷底。

**双参数同时调**：Kp 用 sin 载波、Kd 用 cos 载波，由正交性 `mean(sin·cos)=0`，两路解调互不串扰。

**收敛前提（时间尺度三分离）**：闭环动态（秒级）≪ 载波周期（百秒级）≪ 积分器适应（多窗口）。理论背书：Krstić–Wang 平均化 + 奇异摄动稳定性证明（局部指数稳定）。

### 3.4 工程实现：信号链逐环节

| 环节 | 公式 | 代码位置 | 参数 |
|---|---|---|---|
| 扰动注入（每拍） | `Kp_out=Kp·(1+a·sinφ)`，`Kd_out=Kd·(1+a·cosφ)`，`φ+=ω·dt` | `escDither()` :382-388 | a=5%（escAmp），ω=0.05 rad/s（escFreq，周期≈126 s） |
| 成本增量（每拍） | `c_k=(t_k·\|e_k\|+wU·\|δ_k\|+wDu·\|Δδ_k\|)·dt` | `accumulate()` :366-367 | RingBuffer<3000> |
| 高通去直流（每拍） | `y=αH·(y+c_k−c_{k−1})`，`αH=τH/(τH+dt)` | :369-371 | τH=5 s |
| 因果解调（每拍） | `S_Kp+=y·sinφ`，`S_Kd+=y·cosφ` | :373-375 | 与本拍注入载波同相相关 |
| 梯度归一化（窗末） | `ĝ = 2·S/(a·N)` | `escStep()` :399-405 | ≈ ∂J/∂（增益相对摄动） |
| 梯度低通（窗末） | `grad←(1−αL)grad+αL·ĝ`，`αL=Tw/(τL+Tw)` | :407-409 | τL=10 s，**系数按窗口周期算** |
| 积分更新（窗末） | `K ← K − η·grad` | :411-412 | η=0.02（固定步长） |
| 更新限幅 | `\|ΔK\| ≤ max(\|K_old\|·10%, 1e-3)` | `clampUpdate()` :452-461 | 绝对下限防 Kd=0 永久锁死 |

要点：

- **扰动只存在于输出给 PD 的增益中，不持久化**——`curKp_/curKd_` 保存去载波的中心增益；
- 窗口非重叠（60 s = 3000 拍，结算清零）；
- **P11 整改教训**：旧实现①扰动未真实注入（窗内增益恒定）→ 解调恒为零；②HPF/LPF 系数按 dt=0.02 s 设计却用在每 60 s 才来一个的样本上 → 梯度衰减 2~3 个数量级。结论：**ESC 各环节运行在不同时间尺度（扰动/解调在每拍、LPF 在窗末），滤波器系数必须用各自环节的真实采样周期计算**。

### 3.5 安全机制：四道防线

ESC 更新**不直接生效**，全部增益变更须过稳定门：

1. **四条件稳定门**（`stabilityCheck()` :241-254）：用辨识快照 K̂/T̂ 反解闭环特征——`ωn=√(Kp·K̂/T̂) ≤ 0.5 rad/s`、`ζ=(1+Kd·K̂)/(2√(T̂·Kp·K̂)) ≥ 0.6`、K/T 非退化且 Kp>0、实测振荡峰-峰值 ≤5°；
2. **回退**（`settleWindow_()` :333-345 → `revert()` :429-432）：窗口结算不过门则回退基线——基线永远是"已验证安全"的锚点；辨识快照无效时保守拒绝；
3. **振荡检测**（`OscillationDetector` :257-292）：航向误差过零结算峰-峰幅值（保守取大 + 0.9/0.1 平滑衰减），且**参考稳定满 30 s 后才喂入**——机动期间的误差摆动是指令响应而非闭环振荡；
4. **速度门控**：>15 kn 整体去激活（`highSpeedDeactivateKn` :102, :152），仅层 1 辨识运行。

另有两项生命周期机制：

- **漂移重基线**（P12，`applyEstimate_()` :308-329）：K/T 估计相对基线漂移 ≤25% 时不动作、交给 ESC 自治微调；超阈值说明船况真变 → 重新极点配置 + 过稳定门 + `rebaseEsc()`（:438-450）清零 ESC 积分器/解调/窗口样本（旧梯度围绕旧增益旧模型测得，不得施加到新基线），**载波相位刻意保留**以防重锚拍突跳；
- **挂起**（`suspend()` :199-203）：切到 MANUAL/HOLD 时清测量状态、保留基线，回来无缝续上。

### 3.6 完整调参时序（冷启动 → 收敛）

```
上电 MANUAL → 切 AUTO_HEADING（调度表名义值直通，基线未建立）
→ Z 形激励下 RLS 约 1 min 收敛且 valid
→ 极点配置建立基线（此后增益所有权归 AutoTuner，不再跟随调度表）
→ 每拍注入 ±5% 正交载波 + 逐拍累积解调
→ 每 60 s 窗末结算：归一化梯度 → LPF → 积分更新（±10% 限速）
→ 稳定门通过则持久化，否则回退基线
→ K/T 漂移 >25% 时重基线重锚，循环往复
```

辨识激励的两种来源：① P14 自动 Z 形辨识试验（`startIdentifyTrial(±20°, ±20°, 4 cycles)`，机动收官 `establishBaseline()` 一次性建基线，恒重锚）；② 常规航向机动中辨识器的连续在线评估（漂移门控）。

### 3.7 验证证据

- **单元测试**（90/90 通过）：`EscTunesKpTowardOptimum` 端到端闭环——真实 PD + Nomoto 对象、故意偏低 Kp=0.15 起点，8 个窗口后 Kp 显著增大且窗口成本 J 下降；`WindowSettleUpdateIsClamped` 逐窗断言"被限幅或被回退"；另有载波真实注入（峰-峰 ≈ 2·a·Kp）、零 Kd 解锁、重锚清积分器、稳定门四条件等 14 例专项 + 4 例 core 集成测试。
- **仿真收敛试验**（`ar_sim --tune`，U24~U26）：典型船 K=0.2/T=8 跑 1200 s——辨识误差 +18.2%/+18.5%，18 窗后 J 93639.7→93221.2，末 3 窗散布 ≤10%，converged=1；快船 converged=1；慢船（T=20）ESC 被稳定门按预期阻断（保守钉在安全增益，记录为已知限制）。
- **观测工具**：`plot_convergence.py` 出三图（RLS 收敛、ESC 增益中心轨迹 + 窗口 J 柱状图、含载波全链路概览）；`debug_ui.html` 实时显示 K̂/T̂/J/ζ̂/ω̂n 并支持手动 ESC 一步/回退基线。

### 3.8 选型理由（调研结论）

调研文档（`docs/adaptive_autopilot_research/`，14 章谱系对比）的结论：**"ESC 与 50 年工程共识同构、方向正确"**。

1. **与工业界带宽分离分工同构**：调度表管快变量（航速）、自适应管慢变量（海况/载况残余失配），与 KADPIL（1974）以来的实践一致；
2. **可解释/可认证**：只动 K/T、Kp/Kd 少量物理参数，有平均化稳定性理论，参数可限幅可监控——相对 NN/RL 的取证困难是决定性工程优势；IMO MSC.64(67) 自 1996 年起容纳"自动适应"方案；
3. **激励主动性**：保向工况激励贫乏是一切被动自适应（RLS/NN）的死穴（"需要学习的时候学不动"），ESC 主动注入扰动结构性绕开 PE 问题；
4. **数学定位**：ESC 是"单点、局部梯度、低维的确定性策略搜索"，与 RL 同属无模型在线优化但样本代价极低；天花板是只能在 PD 结构内寻优。

### 3.9 已知限制与改进方向

**当前实现的限制**：

- 无显式收敛停机判据——靠稳定门 + 回退兜底，外部以 J 平台判收敛；
- 默认 ω=0.05 rad/s（周期 126 s）与 60 s 窗口存在张力（窗内装不满半个载波周期，正交解调的整数周期假设不成立）；收敛测试实际改用 `escFreq=2π/60` 等配套参数——默认值更像占位符；
- 固定步长 η=0.02（无自适应步长）；LPF 平滑很弱（αL≈0.857 权重给新样本）；
- 梯度估计量纲为"J 对增益相对摄动"，更新律却做绝对加法——工程近似，由相对限幅兜底；
- 扰动注入影响操舵平顺性；收敛分钟级、慢于 L1/滑模；辨识错误直接传导到极点配置。

**文档已声明的未实现项**：ζ*/ωn* 船速分段（当前单组 0.85/0.20）；回退缓存深度 3（当前单组基线）；代价函数未升级为操舵附加阻力型 `J=E[ψ_e²+λδ²]`（λ≈1/12，节能口径，P1 建议）。

**高海况（4–5 级）适应性**（调研第 8 章 + 结论章）：

- 最大短板：缺**波浪滤波**（陷波/Kalman，P0 建议）——波频分量会淹没 ESC 激励抖动使梯度失真；
- ESC 高海况保护三件套：dead-zone（误差能量低于阈值冻结更新）、泄漏项（防漂移）、激励频率避开遭遇谱峰（0.05–0.2 Hz）；
- 辨识必须用**实际舵角**而非舵令（舵速限制在大信号下引入相位滞后，否则误判"舵效下降"）；
- 降级链：海况超上限时冻结 ESC、切保守 PD 基线、限舵/降速提示；增益调度 PID 是高海况下的安全兜底。

## 4. 仿真、测试与工具链

- **仿真器**（`control/sim/`）：Nomoto 一阶对象（典型 K=0.2/T=8，另有快船 0.5/3、慢船 0.1/20）+ 舵机一阶惯性（τ=0.3 s）+ 舵速/舵角限幅；扰动为恒风等效舵角 + 单频规则波 + LCG 确定性量测噪声；控制与仿真同速率 50 Hz 显式欧拉。8 类场景：step（阶跃指标）、maneuver（6 种机动形态）、ident（RLS 辨识）、trial（P14 自动 Z 形试验）、esc（ESC 长期整定）、tune（全链路收敛）、validate（验证矩阵 + 单拍实时性 <5 ms）。
- **测试**：8 个 GoogleTest 可执行共 90 用例全绿，经 CTest 注册（含 6 个仿真冒烟），大量用例是 P1~P14/R1 整改的锁定回归，可追溯性强。
- **工具链**：`ar_sim → CSV → plot_sim.py / plot_convergence.py / animate_sim.py`；`gen_maneuver_matrix.sh` 生成 3 船型×6 机动×2 干扰 = 36 工况视频矩阵；`debug_ui.html` 在线调试（WebSocket JSON 协议，JS 简化复刻算法，仅供调试不可实船）。
